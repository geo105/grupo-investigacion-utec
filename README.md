# Grupo de Investigación UTEC

Proyectos de investigación de estudiantes de Ingeniería Mecatrónica de la UTEC (Lima, Perú): hardware, código y
documentación de cada uno.

**Web:** https://geo105.github.io/grupo-investigacion-utec/

## Proyectos

| Proyecto | Descripción | Estado |
|---|---|---|
| [Tower](tower/) | Banco torre-hélice de 2 GDL: seis leyes de control (PID, LQI, LQG, MPC, IMC y H∞) implementadas en Arduino y comparadas en el mismo hardware. | Artículo en revisión (IEEE ICSC 2026) |

## Estructura

```
├── index.html             Página principal del grupo
├── assets/                Estilos e ícono del grupo
└── tower/
    ├── index.html         Página del proyecto Tower
    ├── README.md          Uso del firmware
    ├── firmware/          Un sketch de Arduino por ley de control
    ├── firmware_tower.zip Las seis carpetas en un solo archivo
    └── img/               Foto del banco y diagrama de bloques
```
